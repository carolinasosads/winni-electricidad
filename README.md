# Plataforma Digital para Winni-Electricidad
Entregado como requisito para la obtención del título de Analista en Tecnologías de la Información.

Este proyecto presenta el diseño y desarrollo de una plataforma digital personalizada para Winni Electricidad

La solución propuesta consiste en una aplicación web desarrollada con C# sobre .NET, SQL Server Express y React
